# Dunkelmond

Ein 3D-Erkundungsspiel im Browser, im violetten Dark-Fantasy-Stil.
Der Mond ist zerbrochen: Als kleiner Zwerg sammelst du fünf Mondsplitter und bringst sie zum Zauberer, damit er das Tor des Hand-Turms öffnet.

## Spielen

`index.html` im Browser öffnen (Internetverbindung nötig, three.js und Schriften kommen vom CDN).

| | PC | Handy |
|---|---|---|
| Laufen | WASD / Pfeiltasten (Shift = rennen) | Linker Daumen |
| Umsehen | Maus ziehen, Mausrad = Zoom | Rechts wischen |
| Springen | Leertaste | Sprung-Knopf |
| Sprechen | E | Hinweis antippen |
| Ton | M | Lautsprecher-Knopf |

## Gebiete

- **Zauberkessel** – Zauberer Morvan gibt dir den Auftrag
- **Pilzwald** – über leuchtende Sprungpilze auf den Riesenpilz
- **Krötensumpf** – löse das Rätsel der Kröte
- **Augenfels** – beweg dich nur, wenn das Auge geschlossen ist
- **Drachensee** – über auf- und abtauchende Steine zur Insel
- **Totenkopfhain** – zünde die drei Laternen der Zwerge an
- **Hand-Turm** – das Finale

Alles (Grafik, Musik, Soundeffekte) wird im Code erzeugt; es gibt keine externen Bilder oder Audiodateien.
